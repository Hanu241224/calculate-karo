# Calculate Karo

Calculate Karo is a professional calculator platform built with React, TypeScript, Vite, and Tailwind CSS.

## What is included

- Finance calculators for EMI, SIP, GST, and compound interest.
- Health calculators for BMI, calorie needs, water intake, and ideal weight.
- Maths calculators for percentage, average, ratio, and square root.
- Age and date tools for age, day differences, weeks, and time conversion.
- Professional article pages, category filters, search suggestions, bookmarks, sharing, and responsive navigation.

## Local commands

- `npm run dev` starts the local development server.
- `npm run build` checks TypeScript and creates a production build.
- `npm run lint` runs the configured code linter.
